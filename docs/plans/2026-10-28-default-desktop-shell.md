# 默认桌面壳交付

当前范围整理：2026-11-01。关联 G12、G20 及后续模板缺口；状态以[缺口台账](../gaps.md)为准，不重复维护版本和发布进度。

## 边界

Atlas 提供通用几何、轨道、手势和分页；desktop-shell 提供桌面默认呈现、窗口操作、原生菜单与 Atlas 接线。业务导航与 ALwith 品牌不进入 Atlas。模板仅装配共享实现，不覆盖间距、圆角、主题和默认交互。

U、Desktop、WorkBonny、GitCub 共用适用的机制，产品差异通过公共配置或完整替换实现。Desktop 的定制底栏、圆点与独立缩略图能力保留；GitCub 底部 16、不装底栏和分页；TV 保留画板布局，不新增左侧菜单。

## 待统一核对的验收

- 真实窗口拖动、双击、菜单、材质、Atlas 页面切换与资源释放。
- 标准分页排除 -1 和尾部页面；缩略图不混作默认分页按钮。
- 共享顶部与底部几何、默认背景和圆角；消费者无自行覆盖。
- 右下角状态图标使用共享呈现，服务器地址及 CLI 版本由宿主数据接入；无额外重试机制。
- 完整设置和菜单行为按[模板审计](2026-10-30-template-default-audit.md)验证，不能以编译或窗口打开代替。
- 原生能力按实际功能需要请求权限，不因启动或设备检测就请求输入监控。

先在本地候选验证，再与受影响包集中交付；当前先验 macOS，Windows 实机暂缓。创建终点是本地编译并独立运行，不强制安装包验收。没有当前实测证据的条目不能标为完成。
