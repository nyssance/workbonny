# 创建时选择账号能力

日期：2026-10-29。状态：用户明确拍板。

## 决定

create-alwith 和 U 的创建入口提供同一个选择：集成 ALwith 账号，或创建裸聊天。集成账号时默认带登录、账号设置、宠物中心、休息室和桌面宠物；不集成时不生成账号、宠物接线，不安装相关直接依赖，也不授予相关原生权限。

默认登录页面和聊天页面仍是用户拥有、可整体替换的代码。公共能力放进现有 `@alwith/module-auth` 和 `@alwith/module-desktop-shell`，不因这次选择新增包或交付机制。宠物通过应用注入的现有 Runtime 和聊天客户端操作会话，不另建 Runtime 或会话库。

开发、联调、验收使用隔离的本地候选包；全部实现和兼容性验证完成后再统一发布。正式依赖、锁文件不得包含维护者本地源码路径。
