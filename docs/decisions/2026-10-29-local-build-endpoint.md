# create 的终点是用户本机编译并运行

日期：2026-10-29。状态：用户明确拍板。

## 决定

create-alwith 生成的项目能在用户自己的电脑上编译并独立运行，即满足创建流程的交付终点。提供实际可用的依赖与工具链前提、构建和运行命令；不要求用户借助维护者私有源码或本机路径。

U 托管预览、云端构建、签名公证、下载安装不进入 create 流程，也不是本轮完成的前置条件。证书由应用作者按自己的分发需要购买和配置，平台不承担代买或托管责任。不为满足旧计划而新增云端交付服务。

共享能力、默认页面可替换、品牌单一来源、独立性与真实功能验证的要求保持不变。此前完成的云端 CI 构建保留为构建质量证据，不代表面向用户的云端服务承诺。

## 替代范围

本决策替代 [安装产物终点](2026-10-27-acceptance-endpoint-installed-app.md) 中强制安装、零工具链云端交付及 U 提交构建的要求，并收窄 [U 作为入口](2026-10-27-create-alwith-inside-u.md) 中的运行托管责任。旧决策保留为历史，不改写。

原计划的一小时目标不得再以云端排队、签名公证和下载安装作为必测步骤，也不得因为未建设这些服务而判定 create 未完成。
