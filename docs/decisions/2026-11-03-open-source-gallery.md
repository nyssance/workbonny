# 本地图片展厅以完整开源模块交付

日期：2026-11-03。状态：开源与 module 形态已由用户确定；实现尚未完成。

## 决定

用户选择文件夹后，以已认可的「切片节奏」布局浏览本地图片。该功能作为完整开源 module 交付，包括 Rust 实现、前端组件与样式、必要桥接、构建脚本和功能测试。不能只公开薄客户端、隐藏图片处理实现，不能把需要私有 dylib 才能运行的包称为完整开源模块。

本功能不采用 extension，不新增面向扩展宿主的图片 API。Rust 与前端之间必要的调用由模块内部维护。WorkBonny 只组合模块和接入页面，不承接图片引擎实现；其他应用通过同一发行包消费。遵循[默认成品壳与可替换页面](2026-10-28-default-shell-and-replaceable-pages.md)，本次定制不改变共享模板默认首页。

新增原创代码拟采用 MIT，与 WorkBonny 当前许可证一致；这是实施选型，不代表用户已指定许可证。第三方依赖保留各自许可和声明，不能把现有专有模块源码直接改标 MIT。实际开源发行需包含全部自有源码和构建所需文件，并能脱离 ALwith 私有源码独立构建。具体维护仓位置和包名尚未确定，不为此公开 alwith-modules 整仓。

## 功能边界

- 用户主动选择本地文件夹，浏览支持格式的图片；默认不上传、不移动、不修改原图。
- 展厅的五片展示同一张图片，保留连续画面；底部缩略图、键盘切换、原图查看和真实文件信息构成完整浏览流程。
- 缩略图生成和缓存、大图受限解码、目录变化监听由模块负责，具备资源限制、取消和释放机制；不得为快速演示一次性读入整库原图。
- 收藏路径与浏览位置可持久保存；目录失效、权限被撤销、图片损坏明确报错。没有图片时显示选择目录的真实入口，不填充虚构相册。
- 页面卸载释放监听及前端图像资源；模块升级通过公开版本范围和锁文件消费。缓存属于派生数据，与用户原图分离。

## 验收与发行

用真实本地文件验证浏览、切换、增删图片、损坏图片、目录不可用及大图资源限制；验证清洁环境源码构建和模块接入。当前效果图只确认视觉方向，不代表实现或验收完成。

本次开源指令不等于立即发布或推送。全部开发和验证先在本地完成；不触发 CI，推送和发布继续等待用户明确下令。
