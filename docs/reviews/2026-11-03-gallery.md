# 本地图片展厅：Atlas 候选验收

日期：2026-11-03。状态：模块与应用接线已实现，隔离候选通过本页列出的验证；未发布、未推送，不代表正式锁文件或完整聊天应用已交付。

## 所有权与页面

用户确认展厅是 Atlas 内独立的大页面，不是独立系统窗口。WorkBonny 的 `src/gallery.tsx` 只传品牌与可见状态；`src/App.tsx` 通过共享 shell 的 `pages` 接入 `page:gallery`，导航增加“图片展厅”。聊天、预览与已有尾屏保留。

共享 shell 在 alwith-desktop-shell 中增加通用 `DesktopWorkspacePage`，页面参与 Atlas 分页、导航与可见性管理，不在 WorkBonny 复制轨道几何。G39 记录这个上游缺口。

模块维护在 alwith-modules 的 `packages/gallery`，npm 名 `@alwith/module-gallery`，Rust crate 名 `alwith-gallery`，本地候选版本 0.5.0。前端、Rust 实现、构建源文件和测试均以 MIT 交付，不依赖私有图片 dylib 或服务。暂未公开发布。

## 图片行为

用户通过系统选择器选目录；扫描其子目录，跳过符号链接，支持 JPEG、PNG、WebP、GIF 首帧、BMP、TIFF。HEIC、RAW、SVG 未实现。保存上次文件夹和选中项。目录变化显示明确的更新入口；不自动重试，不上传、不修改原图。

五栏自动取同一张图片的连续五等份。普通图片统一适配展示高度，宽度随比例变化；超宽图触及宽度上限后整体缩小、居中，不拉伸、不裁切。四个栏间隙不计入原图的宽高比。悬停回正，减少动态效果时停用位移动画。原貌模式、放大预览和系统应用打开各自可用。

预览最长边 2560 px，缩略图最长边 240 px。一次原图解码同时缓存两种尺寸。前端只派发一个图片任务，大图优先于排队缩略图，失效的排队任务取消；最近图片保留有界 Blob 缓存。原生已开始的解码不抢占，但有文件、像素和内存限制。磁盘派生缓存上限 256 MiB。原图文件上限 128 MiB，像素上限 6400 万，单边上限 32768；目录最多 20,000 张、32 层。正在执行的目录扫描尚无中途取消。

## 验证结果

- 模块类型检查与构建通过；4 个针对性测试通过：原始比例适配、预览优先及过期队列取消、真实图片缩略图与损坏文件处理、符号链接越界拒绝。
- 共享 shell 原有 37 个测试通过，类型检查通过。
- 使用隔离的 WorkBonny 消费者安装本地候选后，完整应用源码类型检查、前端构建、Rust check 与 debug build 通过。本轮没有在正式锁文件中引入维护者路径。
- Hasgard 实机验证 Atlas 第二屏、真实目录中 180 张图片、同图五栏、切换、全图弹层打开及关闭；界面未报告图片错误。实测样本的源图比例与切片画面比例均为 1.7777777778。
- 一张 774,892 字节 JPEG 的原生首次预览 82 ms，随后读取其缩略图 1 ms，缓存预览 1 ms；一次已缓存图片界面切换 27 ms。这些是本机单样本结果，不是所有格式和尺寸的性能保证。
- npm 打包清单验证为 23 个文件、约 109 KB，包含自有源码；不含 Rust target、node_modules 或本地候选 Cargo.lock。

## 运行与未完成边界

本地候选位于 `/private/tmp/workbonny-gallery/consumer`；可运行预览包装为 `/private/tmp/workbonny-gallery/WorkBonny Gallery.app`，依赖正在运行的本地 Vite 1426 端口。它打开专用的 Atlas 验收入口，不启动 Runtime/Codex，未替换 `/Applications` 中的安装版。入口代码仅在隔离目录中，不进入正式应用。

正式 WorkBonny 源码已有完整页面接线；当前维护者安装依赖仍落后于候选源码，尚不能把正式依赖环境视为验证通过。新模块尚未发布，所以不伪造 registry 锁定记录。统一发布授权后还需要安装实际发行物并更新锁文件。

完整应用的签名门禁仍受 G38 阻塞：现有 Codex 原始与暂存二进制一致，但 strict 签名校验失败。本轮未重签、未替换这些厂商文件，也没有运行模型。Windows、HEIC/RAW、极端大目录和完整聊天入口的端到端验收未覆盖。

## 后续界面修正：主展厅不铺缩略图

按用户反馈移除底部缩略图条和装饰性页脚，图片展示区获得额外高度。当前序号、上一张、下一张和“浏览全部”集中在右侧作品信息区。浏览全部打开单行工具栏的搜索网格，每页最多 48 项，只加载可见区域附近的缩略图；选择图片后关闭网格，取消排队请求并释放网格的对象 URL。主展厅只低优先级预加载下一张。

Hasgard 在 180 张真实图片的相册验证：主展厅没有缩略图节点；全部图片共 4 页，第二页 48 项；搜索空状态、完整文件名过滤、选择后回到展厅、关闭后清理缩略图通过。当前 985px 高视口中的图片主体为 675px，页面没有额外纵向溢出。图片保持完整比例，五栏间距 8px。

### 标准组件与 Atlas 验收边界（11 月 3 日补充）

### 原生预览

移除图库自制大图弹层。点击主图或在图库上按空格调用 `workbonny-gallery.preview`；macOS 使用系统 Quick Look，Windows 通过 Tauri opener 使用文件关联的默认图片应用。原文件仍经过选定根目录、窗口与 revision 校验；不经过 shell 拼接，不自动重试。源码、命令注册及权限同步维护于仓内 module。缩略图总览仍用于选图。

原生预览验证：macOS 本地候选重新构建并重启后，Hasgard 实点当前图片启动 `/usr/bin/qlmanage -p <选定原文件>`，页面无权限错误、无自制大图弹层。独立模块 `cargo check --target x86_64-pc-windows-msvc --offline` 通过；Windows 默认图片应用的实机打开尚未验证。此前 Command not found 来自前端热更新领先于旧原生二进制，已通过原生重建与重启消除。
