# Welcome

This app is your own desktop harness for a coding agent. Everything you see in the sidebar comes from the shared ALwith modules; this guide is the `guide/index.md` file in your project, so rewrite it for your users.

## Chats and projects

- **New chat** (the plus button, ⌘N / Ctrl+N) starts a draft. It runs in your quick-chat folder until you pick a project.
- **Select project** above the input lists the folders you have worked in; **New project** opens the folder dialog. A chat in a project folder is registered as a Codex project, so other Codex apps see it too.
- The **Chats** tab groups past conversations by project; double-click it to collapse every group.

## Activity

The **Activity** tab shows what is running right now: the conversation you are looking at first, then background sessions with their latest reply, listening ports and subagent tasks. ⌘1–9 (Ctrl+1–9) jump to a row; the square stops that session only.

## Account

Your account menu at the bottom opens settings, switches the language and signs out. Pets, when enabled for your account, live on the screen to the left.

# 欢迎

这是你自己的桌面编程 Agent 工作台。侧栏里的一切都来自 ALwith 共享模块；这份指南就是项目里的 `guide/index.md`，按你的用户改写它。

## 聊天与项目

- **新对话**（加号，⌘N / Ctrl+N）会先建一个草稿，在你选项目之前运行在随聊目录里。
- 输入框上方的 **选择项目** 列出你用过的文件夹，**新建项目** 打开文件夹对话框。在项目文件夹里的对话会登记为 Codex 项目，其他 Codex 应用也能看到。
- **聊天** 标签按项目分组历史对话；双击它可以收起全部分组。

## 活动

**活动** 标签显示正在运行的会话：先是你正在看的对话，然后是后台会话，以及它们最新的回复、监听端口和子任务。⌘1–9（Ctrl+1–9）跳到对应行；方块按钮只停止那一个会话。

## 账号

底部的账号菜单可以打开设置、切换语言和退出登录。账号启用了宠物时，宠物住在左边那一屏。
